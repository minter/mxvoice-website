## Overview

The Hotkeys panel is on the right side of the Mx. Voice window. It lets you assign songs to the F1 through F12 function keys for instant one-key playback during a show. You get **5 tabs** of hotkey sets, so you can prepare up to 60 songs for quick access.

Your hotkeys are part of the loaded [show](/docs/shows/). Changes are kept only when you save the show with **Shows → Save**.

![Hotkeys panel](/docs/hotkeys-panel.png)

## Assigning Songs to Hotkeys

There are two ways to assign a song to a hotkey:

- **Drag and drop** — Drag a song from the search results and drop it onto any F-key button (F1–F12).
- **Tab key** — Select a song in the search results and press **Tab**. The song is assigned to the first empty hotkey slot.

If you drag a song onto a hotkey that's already occupied, the new song replaces the old one. If the song you're dragging is already assigned to a different hotkey, the two assignments swap.

## Playing Hotkeys

Once a song is assigned, you can play it instantly:

- Press the corresponding **F1–F12** key on your keyboard.
- **Double-click** the hotkey button in the panel.

## Hotkey Tabs

There are 5 numbered tabs at the top of the hotkeys panel. Each tab holds a separate set of 12 hotkey assignments, giving you up to 60 hotkeys total.

- **Switch tabs** by clicking the tab numbers (1–5).
- **Rename a tab** by double-clicking it, or by choosing **Rename** from the **⋯** menu at the end of the tab row. Give each tab a descriptive name like "Intro", "Halftime", or "Endings".

The **⋯** menu (or right-clicking a tab) has every tab action: rename, clear, **Save Tab to File…**, and **Load Tab from File…**.

## Removing Hotkeys

- **Remove one** — Select a hotkey and press **Delete** or **Backspace**.
- **Clear a tab** — Choose **Clear** from the tab's **⋯** menu to remove every assignment in that tab. The songs stay in your library.

## Saving and Loading

To keep the whole layout — all five hotkey tabs and the holding tank — save it as a [show](/docs/shows/) with **Shows → Save** or **Save As…**.

To keep a single tab, save it as a **.mrv file** from the tab's **⋯** menu:

- **Save Tab to File…** — Saves that tab's hotkey set to a .mrv file.
- **Load Tab from File…** — Loads a .mrv file into that tab. If the tab already has songs, Mx. Voice asks first.

A tab file can be loaded into any show, which makes it a good way to reuse a standard set of drops.

## Played Counts

A **▶ count** appears next to any hotkey you've played during the current session. See [Played Counts](/docs/shows/#played-counts).

## Right-Click Menu

Right-click on any hotkey assignment to see a context menu with these options:

- **Play** — Play the assigned song.
- **Edit** — Edit the song's metadata.
- **Remove from Hotkey** — Remove the assignment without deleting the song from your library.
- **Mark as Unplayed** — Clear the song's played count.

## Keyboard Shortcuts

| Shortcut | Action |
| --- | --- |
| **F1–F12** | Play the assigned song |
| **Tab** | Assign selected song to the first empty slot |
| **Delete / Backspace** | Remove the selected hotkey assignment |
| **Cmd/Ctrl+1–5** | Switch to hotkey tab 1–5 |
