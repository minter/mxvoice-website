## Automatic Updates

Mx. Voice checks for updates automatically when the app launches. If a new version is available, you'll see a notification with the version number and release notes.

To look for a new version at any time, choose **Check for Updates…** from the **Mx. Voice** menu on macOS or the **Help** menu on Windows.

### Update Flow

1. A dialog appears showing the new version number and what's changed.
2. Click **Install Now** to start the download. You can also click **Later** to dismiss and update another time.
3. The button shows download progress (e.g., "Downloading... 45%").
4. Once the download completes, the app restarts automatically with a short countdown.

Your songs, profiles, hotkeys, and settings are preserved through the update — nothing is lost.

## Prerelease Updates

By default, Mx. Voice only offers stable releases. If you'd like to try new features early, you can opt in to prerelease (beta) updates in [Preferences](/docs/preferences/) by enabling the **Prerelease Updates** toggle.

The setting is saved per profile, and the profile Mx. Voice opens on decides whether betas are offered.

If you're already running a prerelease version, the updater will automatically check for newer prereleases regardless of the toggle setting.

## Manual Download

You can always download the latest version directly:

- [macOS (DMG)](https://download.mxvoice.app/download/dmg) — Universal binary for Intel and Apple Silicon
- [Windows (EXE)](https://download.mxvoice.app/download/exe) — 64-bit installer
- [All releases on GitHub](https://github.com/minter/mxvoice-electron/releases)

## Release Notes

You can view release notes for any version at any time:

- In the app, the update dialog shows release notes for the new version. **Release Notes** and **What's New** are also in the Mx. Voice menu on macOS and the Help menu on Windows.
- On the web, visit the [GitHub releases page](https://github.com/minter/mxvoice-electron/releases).
